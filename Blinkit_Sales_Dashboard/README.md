# Blinkit Sales Dashboard | Power BI

## Overview

This project presents an interactive **Blinkit Sales Dashboard** developed using **Microsoft Power BI** to analyze sales performance, customer preferences, and product trends. The dashboard transforms raw retail data into actionable business insights through intuitive visualizations, KPI tracking, and interactive filtering capabilities.

The objective of this dashboard is to help stakeholders monitor key business metrics, identify high-performing product categories, evaluate sales trends, and support data-driven decision-making.

---

## Business Problem

Retail businesses generate large volumes of transactional data that can be difficult to interpret without proper visualization. This dashboard addresses that challenge by providing a centralized view of important sales metrics and performance indicators, enabling users to quickly identify trends, opportunities, and areas requiring attention.

---

## Dashboard Features

### Key Performance Indicators (KPIs)

* Total Sales
* Total Orders
* Average Sales Value
* Product Performance Metrics

### Visualizations

* Sales Distribution Analysis
* Category-wise Performance Breakdown
* Sales Trend Analysis
* Funnel Analysis
* Interactive KPI Cards
* Comparative Bar Charts
* Donut Charts
* Line Charts
* Tabular Insights

### Interactive Filters

Users can dynamically filter dashboard results based on multiple criteria to perform detailed exploratory analysis.
